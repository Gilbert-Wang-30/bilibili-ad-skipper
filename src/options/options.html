AI 字幕分析（推荐：最准确的检测方式）

用一个语言模型读视频的 AI 字幕，找出口播广告的起止句。在 167 个有众包标记的视频上，它找到了约 96% 的标记广告，边界误差中位数约 0.1 秒；不设置时只能靠弹幕、热度和关键词，大约能找到一半。需要你自己的 API 密钥：每个视频一次请求，模型拿不准的片段最多再追问 3 次（结果缓存 60 天）。默认模型 Claude Opus 5.5 每个视频约 0.04 美元；Claude Haiku 5.5 在测试集上同样准确，约 0.001 美元（在「模型」里填 claude-haiku-5-5）。

模型服务
API 密钥只保存在本机扩展自己的数据库里（网页和内容脚本读不到），不同步、不导出；只由扩展后台发给你选的模型服务。为防止意外扣费，每小时最多 60 次、每天最多 400 次请求。
模型留空用该服务的默认模型（见上方说明）。
接口地址OpenAI 兼容接口的根地址（…/v1）。本机 Ollama：http://localhost:11434/v1，需先设置环境变量 OLLAMA_ORIGINS=chrome-extension://* 和 OLLAMA_CONTEXT_LENGTH=32768（字幕较长）再重启 Ollama；本地小模型的准确率明显低于在线模型。

隐私：开启后，你看的每个视频的标题和 AI 字幕全文会发送给你选的模型服务（按该服务自己的隐私政策处理），对方因此知道你看了哪些视频；不发送账号、Cookie 或观看记录以外的任何数据。只在有 AI 字幕的视频上运行。

基本

工作模式自动跳过：到达广告段自动跳到结尾；手动按钮：只在播放器右下角显示「跳过广告」按钮。
自动跳过置信度阈值 60%只有置信度不低于该值的广告段才会自动跳过；低于阈值的仍会显示标记和手动按钮。越低越激进，误跳越多。

检测来源

显示与跳转

提示停留时间（毫秒）1000 – 20000。
落点偏移 0 秒跳转目标 = 广告结束时间 + 偏移。负值提前落地（可能看到一点广告尾巴），正值略过结尾。范围 −5 … +10 秒。

关键词

额外「广告开始」弹幕关键词每行一个，作为子串匹配，命中即视为强起始信号。例如：恰饭时间、本期赞助。
额外「广告结束」弹幕关键词每行一个。例如：安全着陆、广告没了。

忽略的 UP 主

在这些 UP 主的视频中不做任何处理每行一个，可填数字 mid 或空间链接（如 https://space.bilibili.com/123456）。保存时自动转换为 mid。
